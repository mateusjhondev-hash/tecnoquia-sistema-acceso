## Descripción
Módulo frontend del sistema de gestión de usuarios de Tecnoquia S.A.S.,
desarrollado con React JS. Implementa las operaciones CRUD (Crear, Consultar,
Actualizar y Eliminar) para el módulo de usuarios, incluyendo validaciones
en todos los campos del formulario.

## Tecnologías utilizadas
- React 18
- React Router DOM v6
- Vite (herramienta de desarrollo)
- CSS puro (sin frameworks externos)

## Cómo ejecutar el proyecto

1. Instalar las dependencias:
```
npm install
```

2. Iniciar el servidor de desarrollo:
```
npm run dev
```

3. Abrir en el navegador: http://localhost:5173
