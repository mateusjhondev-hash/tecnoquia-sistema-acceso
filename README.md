## Como ejecutar

1. Copia la carpeta `tecnoquia-api-v2` a `C:/xampp/htdocs/`
2. Inicia Apache y MySQL en XAMPP
3. Importa `tecnoquia_db.sql` en phpMyAdmin
4. Prueba en Postman con BASE URL: http://localhost/tecnoquia-api-v2
